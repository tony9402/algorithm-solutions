# 공지사항 작성 방법

이 디렉터리에 Markdown 파일을 추가하면 GitHub Pages의 공지사항 탭에 최신순으로 표시됩니다.
파일명은 영문 소문자, 숫자, 하이픈만 사용하고 다음 형식을 지킵니다.

```markdown
---
title: 공지 제목
date: 2026-08-18
---

공지 본문을 Markdown으로 작성합니다.
```

- `title`과 `date`는 필수입니다.
- `date`는 `YYYY-MM-DD` 형식이며 미래 날짜는 사용할 수 없습니다.
- 본문은 비어 있을 수 없습니다.
- 이 `README.md` 파일 자체는 공지로 생성되지 않습니다.
