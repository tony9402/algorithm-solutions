# Algorithm Solutions 참여 및 Pull Request 안내

Algorithm Solutions는 백준, LeetCode, Programmers, HackerRank 등 여러 온라인 저지의 문제 풀이를 함께 모아 공유하는 저장소입니다.

한 사람이 모든 문제와 다양한 풀이를 작성하기에는 한계가 있는 만큼, 이 프로젝트는 여러 사람의 참여를 통해 더 많은 문제와 다양한 접근 방법을 공유하는 것을 목표로 하고 있습니다.

알고리즘 문제를 풀고 계신 분이라면 난이도나 풀이 방식에 관계없이 자유롭게 참여해 주세요. 새로운 문제의 풀이뿐만 아니라 기존 문제와 다른 방식으로 해결한 풀이도 좋은 기여가 될 수 있습니다.

여러분의 많은 관심과 참여를 부탁드립니다.

## Pull Request 제출 전 README를 확인해 주세요

솔루션을 Pull Request로 제출하기 전에 반드시 저장소의 `README.md`를 확인해 주세요.

README에는 다음과 같은 기여 규칙이 정리되어 있습니다.

* 온라인 저지별 솔루션 디렉터리 구조
* 언어별 파일명 및 허용 언어
* `Authored by`, `Co-authored by`, `Link` 작성 방법
* PR 하나당 제출 가능한 솔루션 수
* `Solution Description` 작성 방법
* 코드 스타일 및 언어별 규칙
* `Allow edits by maintainers` 설정
* Pull Request 자동 형식 검사 관련 사항

저장소의 구조를 일정하게 유지하고 리뷰 및 병합 과정을 원활하게 진행하기 위해 필요한 규칙들입니다.

특히 플랫폼별 디렉터리 구조와 파일명, 솔루션 상단의 작성자 정보, 코드 하단의 풀이 설명 등 필수 규칙을 지키지 않은 PR은 수정이 필요하거나 병합되지 않을 수 있습니다.

따라서 PR을 작성하기 전에 README의 **문제 풀이 컨트리뷰트 가이드라인**과 **Rule** 항목을 반드시 확인해 주세요.

## 함께 만들어가는 저장소입니다

하나의 풀이도 프로젝트에 도움이 됩니다.

자신이 해결한 문제의 코드를 공유하고, 다른 사람의 풀이와 접근 방법을 함께 모아 더 유용한 알고리즘 솔루션 저장소를 만들어가고자 합니다.

처음 기여하시는 분들의 Pull Request도 환영합니다.

README의 기여 가이드라인을 확인한 뒤 자유롭게 참여해 주세요.

많은 참여 부탁드립니다.
